# 격자 술래잡기 (ESP32-S3 웹 멀티플레이)

ESP32-S3 보드 하나가 Wi-Fi 공유기 + 웹서버 + 게임 서버 역할을 모두 맡습니다.
플레이어는 휴대폰 브라우저를 조작기로 쓰고, 컴퓨터 브라우저에 게임 화면이 뜹니다.
**앱 설치도, 인터넷도 필요 없습니다.**

```
[ESP32-S3] ──Wi-Fi AP──┬── 휴대폰 브라우저 (조작기: 회전 버튼)
                       └── 컴퓨터 브라우저 (게임 화면: 캔버스)
```

- 12×12 격자 위에서 모든 플레이어가 0.4초마다 바라보는 방향으로 한 칸씩 자동 전진
- 조작은 "시계 방향 90도 회전" 버튼 **하나뿐**
- 술래가 도망자와 같은 칸에 닿으면 잡히고, **잡힌 사람이 새 술래**가 됨
- 장애물이 5초마다 조금씩 바뀜
- 채널(방)로 구분되어 여러 팀이 동시에 플레이 가능

## 빠르게 시작하기

```bash
pio run --target upload
```
펌웨어를 보드에 올립니다.

```bash
pio run --target uploadfs
```
`data/` 폴더(웹페이지)를 보드에 올립니다. **처음 한 번은 반드시 실행해야 합니다.**

```bash
pio device monitor
```
시리얼 로그를 봅니다. 부팅 완료 메시지가 뜨면 준비 끝입니다.

그다음:
1. 휴대폰/컴퓨터에서 Wi-Fi **`ESP32-TAG-GAME`** 에 접속 (비밀번호 `12345678`)
2. 브라우저에서 **`http://192.168.4.1`** 접속
3. 채널 이름(예: `A`)을 넣고 → 컴퓨터는 "게임 화면", 휴대폰은 "조작기"로 참가
4. 2명 이상 모이면 컴퓨터 화면에서 "게임 시작"

> ⚠️ **C++ 코드를 고쳤으면 `upload`, `data/` 폴더를 고쳤으면 `uploadfs`** 입니다.
> 이 둘은 별개이며, 헷갈리면 "고쳤는데 안 바뀌는" 대부분의 문제가 여기서 나옵니다.

## 설정 바꾸기

[include/Config.h](include/Config.h) 한 곳만 고치면 됩니다.

| 상수 | 기본값 | 의미 |
|---|---|---|
| `WIFI_SSID` / `WIFI_PASSWORD` | `ESP32-TAG-GAME` / `12345678` | Wi-Fi 이름과 비밀번호 (비밀번호는 8자 이상) |
| `TICK_INTERVAL_MS` | 400 | 한 칸 이동 간격 — **게임 속도** |
| `MAX_ROOMS` | 4 | 동시 채널 수 |
| `MAX_PLAYERS_PER_ROOM` | 8 | 채널당 최대 인원 |
| `MAP_WIDTH` / `MAP_HEIGHT` | 12 / 12 | 맵 크기 (바꾸면 `GameServer.cpp`의 기본 맵도 같이 수정) |
| `OBSTACLE_UPDATE_INTERVAL_MS` | 5000 | 장애물이 바뀌는 주기 |

> 동시 접속 기기는 **8대 정도가 하드웨어 한계**입니다. `MAX_ROOMS`를 늘려도
> Wi-Fi 단계에서 막히므로 실제 인원은 늘어나지 않습니다.
